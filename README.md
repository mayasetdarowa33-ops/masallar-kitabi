# Masallar Kitabı Projesi
Bu proje, Rus ve Türkmen masallarını bir araya getiren interaktif bir web sitesidir.
## Proje Hakkında
Daha önce tek dosya altında birleştirilmiş olan kodlar, modern web geliştirme standartlarına uygun olarak şu şekilde ayrıştırılmıştır:
- **`index.html`**: Sayfanın iskeleti ve arayüz elemanları.
- **`style.css`**: Sayfanın tasarımı, renkleri ve responsive (mobil uyumlu) düzeni.
- **`script.js`**: Arama, arkaplan değiştirme, masal listeleme ve metin boyutu ayarlama fonksiyonları.
## Nasıl Çalıştırılır?
1. Proje klasörünü bilgisayarınıza indirin.
2. `index.html` dosyasına çift tıklayarak herhangi bir tarayıcıda (Edge, Chrome vb.) açabilirsiniz.
